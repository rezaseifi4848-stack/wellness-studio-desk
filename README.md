# WellnessStudioDesk

یک اپلیکیشن محلی و فارسی RTL برای استودیوی آرامش، یوگا، مدیتیشن، چاکرا و تولید محتوای wellness.

## هدف پروژه

این پروژه فاز اول یک دستیار ساده برای ساخت محتوا، تمرین بیان، متن‌های مدیتیشن، شروع کلاس‌های یوگا و توضیح‌های غیرپزشکی چاکراهاست.

## نکته ایمنی

محتوا آموزشی و حمایتی است و جایگزین درمان پزشکی، روان‌درمانی یا مشاوره تخصصی نیست. برای درد، بیماری، اضطراب شدید، بارداری، آسیب‌دیدگی یا شرایط خاص باید با متخصص قابل اعتماد مشورت شود.

## اجرا روی سیستم محلی

```bash
npm install
npm run dev
```

بعد از اجرا، اپ را در مرورگر باز کن:

```text
http://localhost:3000
```

اگر پورت ۳۰۰۰ پر بود، Next.js یک پورت دیگر پیشنهاد می‌دهد.

## ساختار اصلی

- `app/` مسیرهای Next.js App Router
- `components/` کامپوننت‌های رابط کاربری
- `components/ui/` کارت‌ها، دکمه‌ها و بخش‌های قابل استفاده مجدد
- `data/content/` محتوای محلی JSON برای فاز اول
- `public/` لوگو و تصویرسازی‌های SVG

## ویژگی‌های فاز اول

- بدون دیتابیس
- بدون احراز هویت
- بدون API خارجی
- محلی و قابل توسعه
- فارسی RTL
- Tailwind CSS
- TypeScript
